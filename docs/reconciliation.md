# Phase 1 reconciliation

Use the dashboard's manual price and FX dates to build a separate spreadsheet.
Enter every BDO Securities, IBKR, and Kraken holding and cash balance there,
then convert USD positions using the same stored USD/PHP rate. Record the sheet
total in the app's **Reconcile** screen. A non-zero difference must be explained
in the note before Phase 1 is signed off.

The live reconciliation remains a user-data step: it requires real positions,
prices, FX, and a broker dividend statement that are not stored in this repo.
