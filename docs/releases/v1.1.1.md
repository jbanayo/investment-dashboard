# Version 1.1.1 — Research Draft Comparison

Version 1.1.1 makes replacement-thesis review safer and faster.

## Added

- Draft research cards now detect an existing monitored thesis for the same
  investment.
- The current and proposed thesis summaries appear side by side.
- A change table highlights differences in stance, review condition, time
  horizon, and confidence.
- Drafts with no monitored predecessor retain the normal review layout.
- Monitored cards can open a prefilled replacement-research prompt containing
  the current stance, date, and thesis as review context.
- Any research card can be exported with its sources as a portable Markdown
  file using the same versioned contract as imports.
- Research cards accept locally stored PDF and image source attachments with
  file-signature validation and a 10 MB limit.
- Research history records the first trigger-reached price and archive-time
  price, then shows later performance with a clear non-causal label.

The comparison is informational. The monitored thesis remains active until the
user explicitly chooses **Keep monitoring** on the new draft.
