# Version 1.1.0 — Research and Monitoring

Version 1.1.0 adds a local-first research workflow to the investment dashboard.

## Added

- Manual investment theses with stance, confidence, risks, horizon, and review
  conditions.
- A copyable external-agent research prompt and versioned Markdown template.
- Safe `.md` upload validation and a parsed preview before import.
- AI-assisted drafts with cited sources and immutable original Markdown.
- Draft, Monitoring, Saved, and Archived review states with an audit trail.
- Editing of the working thesis without changing the original import.
- Dashboard monitoring states: Watching, Review due, Price stale, No price, and
  Expired.
- Platform-aware dashboard monitoring, inbox counts, and compact detail views.

## Privacy

The app makes no AI API requests and requires no AI credential. Portfolio data,
research imports, and approval decisions remain in the local SQLite database.

## Upgrade

Start the app normally. Migration 014 creates the research import and preview
tables automatically. Existing portfolio, research, and settings data remain in
place.
