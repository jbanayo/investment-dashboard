# Prototype index

Prototype files are immutable design snapshots. A newer prototype gets a new
number instead of replacing an earlier file.

## Naming

`v<release>-<feature>-prototype.<iteration>.html`

The release identifies the intended product version. The prototype iteration
tracks design changes within that release and is independent of the application
version.
